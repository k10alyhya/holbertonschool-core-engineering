# Python - Exception Handling

This project introduces exception handling in Python and focuses on writing safer and more predictable programs.

## Learning Objectives

- Understand common runtime exceptions.
- Use `try` and `except`.
- Handle specific exceptions.
- Understand `else` and `finally`.
- Raise exceptions using `raise`.
- Write functions that handle errors safely.

## Exception Types

- `TypeError`
- `IndexError`
- `ZeroDivisionError`
- `KeyError`
- `NameError`

## Tasks

- Safe list printing
- Safe integer printing
- Safe list printing with type handling
- Divide two integers safely
- Raise an exception
- Raise an exception with a message
- Exception Handling Quiz
