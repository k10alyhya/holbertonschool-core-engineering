# Python Fundamentals

This directory contains beginner Python projects focused on building a strong foundation in the language.

## Project 1: Environment & First Programs

In this project, I will learn how Python runs code in different ways and how to prepare a clean development environment.

### Main topics

- Python interpreter and REPL
- Expressions vs statements
- Script execution
- Exact and deterministic output
- `pip` and development tools
- `pycodestyle`
- Virtual environments with `venv`

### Tasks

- Interpreter Reasoning
- Deterministic Script Output
- Installing and Using `pycodestyle` with `pip`
- Virtual Environment Isolation

The goal is not only to complete the tasks, but to understand how Python executes code and how development environments work.
